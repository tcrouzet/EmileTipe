# Instructions locales du projet

## Gestion de Git

- Ne jamais exécuter `git commit` ni `git push`.
- Ne jamais créer de tag ou publier une release.
- L'utilisateur réalise lui-même les commits et les publications.
- Il est permis de modifier les fichiers, d'exécuter les tests et de préparer les changements dans le répertoire de travail.
- À la fin d'une intervention, indiquer les fichiers modifiés et laisser les changements non commités afin que l'utilisateur puisse les examiner.
